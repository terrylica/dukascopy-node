# AI US-Stock 5-minute Data Pack (Dukascopy)

Historical **5-minute OHLCV** bars — **bid, ask, and computed mid** — for **28 actively-traded,
AI-related US stocks** plus one bonus AI ETF, sourced from **Dukascopy** stock-CFD quotes.

- **Live page (start here):** <https://eon.25u.com/ai-stocks/>
- **Machine-readable index:** <https://terryli-dukascopy-ai-stocks.s3.us-west-2.amazonaws.com/v1/manifest.json>
- **Download everything:** <https://terryli-dukascopy-ai-stocks.s3.us-west-2.amazonaws.com/v1/ai-stocks-m5-all.zip>
- **Checksums:** <https://terryli-dukascopy-ai-stocks.s3.us-west-2.amazonaws.com/v1/CHECKSUMS.txt>

Prices are **split-adjusted**; timestamps are **UTC** (bar OPEN time). The data is Dukascopy **CFD
quotes** (bid/ask), not the consolidated exchange tape; volume is indicative. Market-cap and
liquidity figures on the page are **live from Nasdaq's API**; AI-relevance and retail-buzz scores are
clearly-labelled editorial estimates. All bars are integrity-checked (5-min-aligned, UTC, strictly
increasing, no duplicates — 4.25M bars validated).

## Step 0 in detail — registering the Dukascopy demo account (human, required)

The data is acquired through Dukascopy's own platform, which requires a **free demo account**.
**This registration is a manual, human task** — a person fills the form; it is not scriptable.

1. Go to **<https://www.dukascopy.com/swiss/english/forex/demo-fx-account/>**.
2. Fill in the registration form (name, email, country, phone). Use an email you can read.
3. Submit. **No email confirmation / click-to-verify is required** — the account is usable immediately.
4. Within a few minutes you receive an email titled **"Time to Trade with Your New Demo Account" /
   "Your Demo Trading Account Is Ready"** from _Dukascopy Europe IBS AS_. It contains the
   **JForex 4 login data (FX/CFD)**: a **Login** (e.g. `DEMO2xxxxxxxxxx`) and a **Password**.
5. Keep those credentials. The web platform is at
   **<https://eu-demo.dukascopy.com/web-platform/>** (log in with the emailed Login/Password).

The demo account is your authorized access to Dukascopy's market data and platform. The bar data
itself is then pulled from Dukascopy's public **chart API** (`freeserv.dukascopy.com/2.0`), which the
web platform uses under the hood — so `freeserv_fetch.ts` needs no credentials stored in the scripts.

## How the data is obtained (method)

Dukascopy's bulk tick archive (`datafeed.dukascopy.com`) rate-limits/blocks repeated requests from a
single IP. The breakthrough was the **JForex web platform's own chart backend**:

```
GET https://freeserv.dukascopy.com/2.0/index.php
      ?path=chart/json3
      &instrument=NVDA.US/USD     (URL-encoded; ".US/USD" stock-CFD symbols)
      &offer_side=B               (B = bid, A = ask)
      &interval=5MIN
      &splits=true                (split-adjusted prices)
      &limit=6000                 (up to ~6000 candles per request)
      &time_direction=P           (P = paginate into the past from `timestamp`)
      &timestamp=<ms, 5-min-aligned>
```

It returns `[[ts_ms, open, high, low, close, volume], ...]`. Crucially, **freeserv generates the JSON
server-side from Dukascopy's archive** — your IP never touches the rate-blocked CDN, so this path is
not subject to the block. It is free, needs no login, supports bid and ask, is split-adjusted, and
goes back to each instrument's inception (e.g. NVDA to 2017). `freeserv_fetch.ts` paginates backward
with `time_direction=P` until each instrument's full history is collected.

## Scripts (ai-stocks/)

| File                     | Purpose                                                                                                                       |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| `instruments.json`       | Frozen universe: ticker → Dukascopy symbol → history start date                                                               |
| `freeserv_fetch.ts`      | **The data pull** — 5-min bid+ask for every instrument via the freeserv chart API → `raw/`                                    |
| `freeserv_run.sh`        | One-shot driver: fetch → build → upload → render → deploy                                                                     |
| `fetch_fundamentals.ts`  | Live market cap + average volume from Nasdaq's API → `fundamentals.json`                                                      |
| `validate_timestamps.ts` | Integrity gate: format, 5-min alignment, monotonic, no dupes, UTC proof                                                       |
| `build_outputs.ts`       | Merge bid/ask, compute mid, validate, gzip/zip, SHA-256, `manifest.json`                                                      |
| `upload_s3.ts`           | Create public-read S3 bucket and upload artifacts                                                                             |
| `render_page.ts`         | Generate the CEO-facing `site/index.html` from the manifest + rankings                                                        |
| `rankings.ts`            | Editorial AI-relevance / retail-buzz scores (clearly labelled as estimates)                                                   |
| `web_platform_probe.ts`  | How the freeserv endpoint was discovered (drives the web platform via a browser)                                              |
| `jforex-dl/`             | Investigation record: a headless JForex-SDK (Java) downloader (the SDK route hits the same blocked CDN — kept for provenance) |

Heavy outputs (`raw/`, `build/`) and credentials are git-ignored; the data lives on public S3.

## Requirements

- [Bun](https://bun.sh) (TypeScript runtime). `cd ai-stocks && bun install`.
- For `upload_s3.ts`: AWS credentials with S3 write access.
- For reproduction from scratch: a free Dukascopy demo account (Step 0 — human).
